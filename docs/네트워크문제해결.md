# 네트워크 문제 해결서

## 진단 결과 색상 의미

| 색 | 의미 | 조치 |
|---|---|---|
| 초록 | 외부 회의 가능, 20명 발표 모드 권장 | 그대로 회의 시작 |
| 노랑 | 외부 회의 가능, 인원·화질 제한 권장 | 10명 이하 또는 저대역폭 모드 |
| 빨강 | 포트 접근 불가 | 수동 포트포워딩 후 재검사 |
| 회색 | CGNAT 또는 관리형 네트워크 | 외부 방 개설 미지원. LAN 회의 또는 다른 회선 사용 |

## 기본 포트

| 용도 | 포트 | 프로토콜 |
|---|---:|---|
| 시그널링 | 44330 | TCP |
| WebRTC 미디어 | 44331 | UDP |
| UDP 차단 시 미디어 대체 | 44331 | TCP |

포트가 사용 중이면 앱이 다음 번호로 대체하며 초대코드에 자동 반영됩니다. 설정에서 기본 포트를 바꿀 수 있습니다.

## 증상별 해결

### "UPnP 포트 매핑에 실패했습니다"
1. 공유기 관리 페이지(보통 192.168.0.1 또는 192.168.1.1)에서 **UPnP** 를 켭니다.
2. 켤 수 없으면 **포트포워딩** 메뉴에서 아래 규칙을 이 PC 로컬 IP 로 추가합니다.
   - TCP 44330 → PC
   - UDP 44331 → PC
   - TCP 44331 → PC
3. PC 로컬 IP 가 바뀌지 않도록 공유기에서 **DHCP 고정 할당** 을 설정합니다.
4. 회의 열기에서 **UPnP 건너뛰기** 를 켜고 시작합니다.

### "공인 IPv4 가 아닌 주소가 확인되었습니다 / CGNAT 의심"
- 공유기의 WAN(인터넷) IP 가 `100.64.x.x ~ 100.127.x.x` 또는 `10.x`, `192.168.x` 이면 통신사 CGNAT 또는 이중 NAT 입니다.
- 이중 NAT(공유기 두 대)인 경우: 상위 공유기에서 하위 공유기로 같은 포트를 한 번 더 포워딩하거나, 하위 공유기를 브리지(AP) 모드로 바꿉니다.
- 통신사 CGNAT: 통신사에 공인 IP 할당을 요청하거나(유료일 수 있음), 다른 회선에서 방장을 맡습니다. 이 앱은 중계 서버 없이 CGNAT 를 우회하지 않습니다.

### "STUN 응답이 없습니다"
- 인터넷 연결을 확인합니다.
- 회사·학교 망은 UDP 를 차단할 수 있습니다. 이 경우 방장 기능을 사용할 수 없습니다.

### 참가자가 "방장 PC 에 연결할 수 없습니다"
- 방장이 회의를 열어둔 상태인지, 초대코드가 만료되거나 재발급되지 않았는지 확인합니다.
- 방장 Windows 방화벽에서 SJTing 이 **개인 및 공용** 모두 허용되었는지 확인합니다 (Windows 보안 → 방화벽 → 앱 허용).
- 방장이 진단에서 헤어핀 검사가 노랑이라면 실제 외부 참가자 1명으로 접속을 시험합니다.
- 참가자 쪽 네트워크가 특정 포트로의 아웃바운드를 막을 수 있습니다(기관망). 모바일 핫스팟으로 재시도합니다.

### "인증서 검증 실패"
- 초대코드의 지문과 방장 인증서가 다릅니다. 방장이 앱을 재설치했거나 초대코드가 다른 PC 의 것입니다. 새 초대코드를 받으세요. 임의로 무시하고 입장하는 기능은 제공하지 않습니다.

### 음성이 끊기거나 화면공유 글자가 흐림
- 방장 회선의 업로드가 부족합니다. 회의 헤더의 **서버 ↑ Mbps** 를 확인하고, 모드를 **발표** 또는 **저대역폭** 으로 바꾸거나 인원을 줄입니다.
- 방장은 유선 연결을 사용합니다. 와이파이는 패킷 손실이 커서 권장하지 않습니다.
- 화면공유는 **문서 모드** 를 선택합니다.

### 회의가 갑자기 종료됨
- 방장 PC 의 네트워크 인터페이스나 공인 IP 가 바뀌면 앱이 회의를 종료합니다(기존 초대코드 무효). 새 회의를 만듭니다.
- mediasoup 미디어 엔진이 비정상 종료되면 안전하게 회의를 마칩니다. 설정 → 로그 내보내기로 로그를 확인하세요.

## 방장 회선 권장 기준 (실측 기준)

| 회의 형태 | 업로드 권장치 |
|---|---:|
| 10명 이하, 화면공유 중심 | 100Mbps 이상 |
| 20명, 발표 모드 | 200Mbps 이상 |
| 20명, 다수 카메라 활성 | 300Mbps 이상 |

앱은 외부 속도측정 서비스를 사용하지 않습니다. 회의 중 실제 전송량의 최대치를 기록하고 다음 진단의 권장 인원 계산에 사용합니다.
