# SJTing 사용자 안내서

## 설치

1. [GitHub Releases](https://github.com/dacisosl/sjting/releases) 에서 `SJTing-Setup-x.y.z.exe` 를 내려받습니다.
2. 실행 시 Windows SmartScreen 경고가 나오면 **추가 정보 → 실행** 을 누릅니다. (MVP 는 코드사이닝이 적용되지 않았습니다.)
3. 설치 경로를 선택하고 설치합니다. 첫 실행 시 개인정보·네트워크 한계 안내를 확인합니다.

## 삭제

Windows 설정 → 앱 → SJTing → 제거. 설정 파일(`%APPDATA%\SJTing`)은 기본적으로 남으며 직접 삭제할 수 있습니다.

## 업데이트 (수동)

새 버전 설치파일을 내려받아 그대로 실행하면 덮어쓰기 설치됩니다. 방장과 참가자의 앱 버전이 다르면 초대코드 버전 불일치로 입장이 거부될 수 있으니 함께 업데이트하세요.

## 회의 열기 (방장)

1. 홈 → **네트워크 진단 먼저 하기** 로 초록/노랑/빨강/회색 판정을 확인합니다.
2. 홈 → **회의 열기** → 표시 이름, 접속 범위(외부 / LAN), 기본 모드를 고르고 **회의 시작**.
3. 처음이라면 Windows 방화벽 허용 창에서 **개인 및 공용 네트워크** 모두 허용합니다.
4. 초대코드 창이 뜨면 **초대 링크 복사** 후 참가자에게 전달합니다. 초대코드에는 방장 공인 IP 가 포함되니 신뢰하는 사람에게만 보내세요.
5. 회의 중 컨트롤 바에서 모드 변경, 입장 잠금, 전체 음소거, 초대코드 재발급을 할 수 있습니다.
6. **회의 종료** 를 누르면 모든 참가자가 나가고 UPnP 포트 매핑이 해제됩니다.

## 회의 참가

1. 홈 → **초대코드로 참가** → 표시 이름 입력.
2. 받은 `sjting://join/...` 링크를 클릭하거나 초대코드를 붙여넣기 합니다.
3. 유효한 초대이면 방장 주소(마스킹)와 인증서 지문 일부가 표시됩니다. **참가**.
4. 컨트롤 바에서 마이크·카메라·화면공유·손들기를 켜고 끕니다.

## 회의 모드

| 모드 | 동작 | 권장 상황 |
|---|---|---|
| 발표 모드 | 화면공유 1개 크게, 발표자 카메라 우선, 나머지 저화질 소형 타일 | 수업·회의·발표 |
| 대화 모드 | 최근 발언자 6명까지 영상 수신, 나머지는 이름 표시 | 토론 |
| 전체 보기 | 최대 20명 타일, 화면에 보이는 타일만 초저화질 수신 | 출석·인원 확인 |
| 저대역폭 모드 | 음성 우선, 화면공유 720p, 카메라는 발언자 1명 | 불안정한 회선 |

## 화면공유

- **문서 모드**: 1080p, 10fps, 글자 선명도 우선. PPT·PDF·수업자료용.
- **동영상 모드**: 30fps, 부드러움 우선, **PC 소리 함께 공유** 선택 가능.

## 문제가 생기면

- 연결이 잠시 끊기면 30초 동안 자리가 유지되고 자동으로 다시 연결합니다.
- 방장 PC 의 네트워크나 공인 IP 가 바뀌면 회의가 종료되며 새 회의를 만들어야 합니다.
- 설정 → **로그 내보내기** 로 진단 로그를 저장해 문제를 신고할 수 있습니다. 로그에는 토큰·전체 IP·채팅 내용이 포함되지 않습니다.
- 네트워크 관련은 [네트워크 문제 해결서](네트워크문제해결.md) 를 참고하세요.
