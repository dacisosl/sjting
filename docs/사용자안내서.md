# SJTing 사용자 안내서

## 가장 쉬운 방법: 설치 없이 웹으로

1. 방장이 보낸 링크(`https://sjting-server.sjting-server.workers.dev/join/…`)를 크롬이나 엣지에서 클릭합니다.
2. 이름을 입력하고 **브라우저로 참가**.
3. 방을 만들 때도 같은 주소로 들어가 **회의 만들기**.

스마트폰 브라우저에서도 참가할 수 있습니다(화면공유는 PC 만). 설치형 앱은 화면공유 선택창과 시스템 오디오가 더 편할 때 쓰면 되고, 웹 참가자와 같은 회의에 들어옵니다.

## 설치형 앱 설치

1. [GitHub Releases](https://github.com/dacisosl/sjting/releases) 에서 `SJTing-Setup-x.y.z.exe` 를 내려받습니다.
2. Windows SmartScreen 경고가 나오면 **추가 정보 → 실행**.
3. 설치 후 첫 실행 시 안내를 읽고 **이해했습니다**.

계정, 공유기 설정, 포트 설정은 없습니다. 인터넷만 연결되어 있으면 됩니다.

## 회의 만들기

1. 홈 → **회의 만들기** → 표시 이름 입력 → **회의 시작**.
2. 초대 링크 창이 뜹니다. **복사** 를 눌러 카톡·메일로 보내세요.
3. 마이크·카메라 버튼을 눌러 켭니다. 처음엔 Windows 권한 창이 뜰 수 있습니다.
4. 회의가 끝나면 **회의 종료**. 방장이 5분 이상 자리를 비우면 자동 종료됩니다.

## 회의 참가

1. 받은 `sjting://join/…` 링크를 클릭하면 앱이 열립니다. 안 열리면 앱에서 **초대코드로 참가** 후 링크를 붙여넣기.
2. 표시 이름 입력 → **참가**.

## 회의 모드 (방장이 변경)

| 모드 | 동작 | 권장 상황 |
|---|---|---|
| 발표 모드 | 화면공유 1개 크게, 발표자 카메라 우선, 나머지 저화질 소형 타일 | 수업·회의·발표 |
| 대화 모드 | 최근 발언자 6명까지 영상, 나머지는 이름 표시 | 토론 |
| 전체 보기 | 최대 20명 타일, 화면에 보이는 타일만 저화질 수신 | 출석·인원 확인 |
| 저대역폭 모드 | 음성 우선, 화면공유 절반 화질, 카메라는 발언자 1명 | 불안정한 회선 |

## 화면공유

- **문서 모드**: 1080p, 10fps, 글자 선명. PPT·PDF·코드.
- **동영상 모드**: 30fps, 부드러움 우선, **PC 소리 함께 공유** 가능.

## 방장 기능

컨트롤 바에서 초대 링크 보기·재발급, 입장 잠금, 전체 음소거 요청, 참가자 목록에서 강퇴.

## 자주 묻는 것

- **비용?** 무료입니다. 운영자의 월 무료 한도 안에서 제공되며, 홈 화면에 이번 달 사용률이 표시됩니다. 한도를 다 쓰면 다음 달 1일까지 새 회의를 만들 수 없습니다.
- **영상이 저장되나요?** 아닙니다. 실시간으로 중계만 하고 채팅은 회의 종료 시 삭제됩니다.
- **연결이 끊겼어요.** 30초 안에 자동으로 다시 연결합니다. 상단에 "다시 연결 중" 이 보입니다.
- **소리가 안 들려요.** 설정 → 스피커 장치 확인. Windows 소리 설정에서 출력 장치도 확인하세요.
- **문제 신고.** 설정 → **로그 내보내기** 파일을 첨부하세요. 토큰·채팅 내용은 들어 있지 않습니다.
